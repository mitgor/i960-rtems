Offline mutation tests pass.

Operation 7 accepts the existing zero-DMA `0x8f` mailbox envelope with fixed nonce `0x16161071`. A separate 16-byte host-written control at `c000f870` contains `HASH`, the same nonce, page count 1–127, and expected FNV-1a. The card verifies the retained 512 KiB owner record and grant range, invalidates D-cache, hashes exactly the requested contiguous pages starting at the grant base, and returns `HASH`, nonce, page count and digest at `c000f830` only if the digest matches. A bad count or digest returns stock unsupported status. FNV detects transfer errors; it is not a cryptographic authenticity check. The host still pins exact firmware/module hashes.

Before programming, a guarded 1 MiB `READIMAGE` matched the prior candidate, and `STOREIMAGE` plus independent guarded 1 MiB `READIMAGE` matched this candidate. One `FLASHIMAGE` completed in 37.024 seconds with status/residual zero. The old DAC960PG `37:04.1` stayed unbound. Full data reads remain on the test PC; compact receipts will be added after post-boot acceptance.

The prepared [host harness](../../../host/accele160/digest/run_digest.py) is limited to two deterministic contiguous pages. It requires two same-boot full-flash reads, checks card identity, owner metadata and both page-copy checksums, then requests the card-computed digest over all 8 KiB. It restores staging, control/result slots, loader page and allocator ownership before unloading companions. [Replay verifier](../../../host/accele160/digest/verify_live.py) is ready for captures. No RTEMS or Doom code is called by this operation.
