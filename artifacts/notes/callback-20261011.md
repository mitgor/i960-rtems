The recommended 50 us variant reduces full-frame callback time **38.28%**, kernel
transaction time **19.44%** and host-step wall time **18.54%**. Header-only callback
time falls from 4.9900 to 1.4739 ms. The validator-only session attributes about
3.51 ms of the full-frame improvement to request scanning; the renderer changes
save another 1.06 ms. These are differential host intervals, not target cycles.

The 20 us experiment passes all the same validation. It saves another 0.269 ms
(**2.58%**) of audit time and 0.513 ms of total kernel time, at **17.19% more host
process CPU time** than the optimized 50 us variant. Keep it an explicit optional
latency tradeoff. The recommended release retains 50 us, avoiding that CPU cost.
With detailed command profiling disabled, its additional 421-request session
measures **7.3576 ms callback / 10.3230 ms audit / 19.3519 ms kernel total**.

Read waits remain the largest cost: optimized 50 us runs spend 9.4615 ms in audit
read completion waits, versus 0.3452 ms scanning DMA contents. Their combined
command time is 10.1439 ms. Ordinary frames still read **942,272 bytes** in paired
snapshots; every 32nd request reads **1,048,576 bytes**. Neither audit byte count,
chunk sequence nor cadence changed. Smaller sleep intervals cannot remove the
underlying transfer/firmware work. No browser FPS or raw bus-bandwidth claim is
made. OS copy/clear and RTEMS semaphore/tick implementations are unchanged.

Use `build_target.py --request-words --render-fast` and
`callback/build_transport.py --out DIR --coarse` for the accepted combination.
Existing target-builder defaults and production `autonet` remain unchanged.

sessions in `../upload-20261011/live.tar.gz`; it is historical evidence, not a new
candidate measurement. Header-only callback medians are 5.006/4.990 ms and full

  request padding/guards/output. Every original byte and header check remains.

  two-second deadline and every transaction/validation operation are identical.

source profiles, modified request headers, source-hash manifests, all three generated

workspace `/home/mit/i960-callback-20261011-1jOTHm`; the existing RTEMS/newlib
source archives and toolchain were reused read-only.

## Next bottleneck

A larger improvement to readback requires an explicit transport/ownership
redesign, such as a generation-checked frame queue with an independently audited
immutable region. This work does not implement that contract. Keep paired full
coverage until a replacement proves equivalent integrity and cancellation rules;
do not quietly sample fewer bytes or remove immutable checks for a better FPS.
The parallel internal-controller finding does not itself grant additional RAM
or allow direct NIC DMA in this bounded path.
