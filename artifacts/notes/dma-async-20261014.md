# Task-owned asynchronous DMA — 2026-10-14

Both the STOP and session-deadline batches are physically accepted.
DMA remains an opt-in diagnostic, separate from Doom framebuffer delivery.

## Ownership and protocol

Worker 1 owns the fixed source buffer, descriptor, DMA1 launch, bounded polling,
and source/descriptor validation. It already has an audited RTEMS interrupt stack;
no additional task or unowned ISR continuation was introduced. Submission through
MU only stages arguments and publishes one job. Target report word 31 is a volatile
phase: 1 pending, 2 terminal. While pending, argument edits and duplicate starts
are refused. A compiler barrier precedes terminal publication.

Linux ioctl `0xc4204d07`, 1,056 bytes, now separates op 1 submission from op 3
completion. Op 3 requires zero length/offset/seed, returns EAGAIN while pending,
and performs all 32 report reads and all 73,728 destination/guard checks before
accepting completion. Op 2 reads the complete captured buffer in 1 KiB pieces.
The session mutex is released between calls, so STOP is not blocked behind the
job. Users still cannot choose DMA addresses. All mappings remain pinned until
reboot, even after success/cancellation. No flash, ATU or RAM-boundary change.

STOP before launch cancels with target error 10 and no destination writes. The
worker services even a job accepted immediately before its stop flag. STOP after
launch lets the bounded poll/check finish before worker retirement: CCR disable
is never claimed as an abort. A real DMA error or polling exhaustion poisons the
job, retains memory and refuses further work. Native tests cover those branches;
this batch does not claim a physically hung DMA engine was induced or recovered.

Cancellation reports retain the preceding transfer's register samples; they are
not a new completion claim. The separate cancellation oracle checks that fact,
all untouched destination bytes and the cancellation status. The unchanged full
system oracle checks engine isolation, ISR lifetime, stack/RAM guards and heap
retirement. No audit fields or conditions were suppressed to accept this run.

## Reproduction

Build with the same flags as the synchronous proof:

```sh
python3 project/rtems/build.py --work "$PWD" --profile residentnet \
  --secondary-reset --fault-owner --extra-ram --general-heap --heap-shared \
  --queue-reclaim --owned-mib 12 --dispatch-atomic --dma-proof
python3 project/rtems/residentnet/ram_audit.py residentnet
python3 project/rtems/residentnet/build_transport.py \
  --payload residentnet/kernel.bin --out residentnet-module
make -C /lib/modules/$(uname -r)/build M="$PWD/residentnet-module" modules
sudo python3 project/rtems/residentnet/live.py \
  --payload residentnet/kernel.bin --module residentnet-module/dac960auto.ko \
  --output live --secondary-reset --fault-owner --extra-ram --general-heap \
  --heap-shared --queue-reclaim --owned-mib 12 --ticks 60000 --rounds 1 \
  --dma-proof --dma-stop
```

Run `rtems/dma/test_target.py`, `test_host.py`, `test_replay.py` for native tests.
Replay an extracted archive using its `project/rtems/residentnet/verify.py
--root ROOT ROOT/live`, `project/rtems/dma/verify.py --root ROOT ROOT/live`, and
`project/rtems/dma/verify_stop.py ROOT/live`. Keep evidence immutable. Copy and
hash-verify closed archives locally before reboot; never force unload.
