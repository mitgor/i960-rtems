# T3 long hardware replay and timing evidence

Collected 2026-10-10 Europe/Berlin; see ../../TETRIS-REPLAY.md.

- replay.tar.xz: all 1,000 primary transactions, exact requests/responses,
  full captures in lossless XOR/ZIP encoding, metadata and timing rows.
- repeat.tar.xz: separate 64-call repeat and equivalent complete evidence.
- smoke/: initial three-call instrumented-module/archive smoke test.
- validation.json, repeat-validation.json, smoke-validation.json: independent
  local reconstruction, native oracle comparison, continuity, ID/status/guard,
  one-execution and RAM-restoration checks for every transaction.
- summary.json, repeat-summary.json, progress.jsonl: timing and outcome data.
- latest-frame.txt: final primary frame, directly readable.
- module/: exact timed kernel module and generated source. Game/runner/flash
  unchanged; game payload is ../tetris-t2-20261010/target/tetris_payload.bin.
- source/: replay/archive/validator/loader and native game source snapshot.
- native-tests.txt: ten offline tests including 194 scalar and 230 BIO1
  command-boundary faults, archive round-trip and deterministic scheduling.
- final-host-state.txt: final kernel/boot, with successful module-absent and
  driverless checks at collection.

The main run has 974 updates, 19 initializations/restarts and seven quits. The
repeat has 63 updates and one initialization: 1,037 update calls in total.
All 1,064 main/repeat transactions completed 128 commands and unloaded. Including
three smoke transactions gives 136,576 successful firmware commands. All tests
used boot a9429ca4-0144-452d-8a80-7189608ce99b; no reboot or flash write occurred.
Recovery remains untested. The stress input produced no scored line clear; T2's
constructed two-line test is the live line-clearing evidence.

Extract the tar.xz into a new directory. Use host/loadrun/validate_replay.py to
check its replay/ or repeat/ tree against a compiled game/oracle.c. Use
capture_archive.py with baseline.bin to reconstruct raw captures from an inner
ZIP. ZIP data members may be XOR encoded, not directly usable firmware images.
Hashes and sizes validate the original bytes. All files are intended for Git;
repository-wide SHA256SUMS and artifact-inventory.json include this archive.
