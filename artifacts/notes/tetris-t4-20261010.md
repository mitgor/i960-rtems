# T4 SSH Tetris evidence — 2026-10-10

See [TETRIS-TERMINAL.md](../../docs/games/TETRIS-TERMINAL.md) for the play command,
implementation contract, measurements and reproduction instructions.

The 30-minute automated real-SSH run completed **35,846 native-matching frames**
and **68 restarts**. Elapsed time 1,800.236 s; 19.91 Hz; median call 42.33 ms,
p95 43.54 ms. There were 159 skipped render slots, 2,971 late completions,
maximum scheduling lateness 380.43 ms, and no dropped simulation ticks.
A deliberate input flood dropped 96 actions. Full final RAM restoration and
module unload passed. No flash write or reboot.

- `evidence.tar.xz`: full remote captures and traces for `smoke` (244 frames),
  `disconnect` (102), `reconnect` (64), `endurance` (35,846) and `resize-launcher`
  (124). Extract into a new directory. Each run contains module preflight,
  OPEN/CLOSE debugfs captures, metadata, gzip request/response trace, summary,
  and final game state/frame. These are ordinary files after extraction.
- `ssh/`: Mac-side compressed ANSI terminal transcripts, exact timed key events,
  exit status and remote TTY-restoration markers for all five tests. `resize`
  here corresponds to `resize-launcher` in the remote archive.
- `*-summary.json`: directly readable hardware-run statistics.
- `*-validation.json`: independent native-C comparisons and full restoration
  checks. All **36,380** frames across five runs matched. The partial checkpoint
  independently checked the first 11,514 endurance frames while it was running;
  its prefix SHA256 was also matched against the completed trace.
- `terminal-tests-{macos,linux}.txt`: five frontend tests on each platform.
- `installed-help.txt`: installed launcher invocation/help check.
- `final-host-state.json`: exact installed hashes, same boot, no DAC960 module
  and no bound controller driver. Installed frontend/launcher hashes match the
  local source snapshot; the final state was collected after the resize test.
- `module/dac960session.ko`: exact T5 module, unchanged, kernel 6.8.0-138-generic.
- `target/`: exact unchanged i960 T2 payload and the Mac native comparison library.
- `source/`: frontend, session/transport dependencies and game/target sources;
  includes a documentation snapshot. The kernel's generated source and its
  failure-test evidence remain in `../tetris-t5-20261010/`.

The gzip trace uses fixed little-endian `<QQQ256s2160s` records: call start since
loop start, call duration, lateness (nanoseconds), game request and card response.
`host/session/validate_terminal.py` reconstructs the state chain, calls the native
C implementation and checks exact outputs and the final paired RAM captures.

The controller spent 15,733 endurance responses in the running phase, 20,112 in
game-over and one in quit. Scripted keys restarted it periodically. This was
an automated test through the actual SSH input/render loop, not human play.
Disconnect deliberately killed only the local SSH test process; the remote
client saw EOF and performed cleanup. A fresh SSH connection then quit with
Ctrl-C. Resize paused at 40×12 and resumed at 80×24 through the installed launcher.

The tested card is PCI `0000:37:09.1`, firmware 4.07-0-29, 16 MiB DRAM, on boot
`a9429ca4-0144-452d-8a80-7189608ce99b`. Recovery and RTEMS were not part of T4.
