# Exact point-side replacement acceptance

Specialized C columns remain opt-in and are explicitly enabled on both sides.
The playable exact divide stays default. New `--fast-point-side` replaces only
R_PointOnSide; the protected original O0 helper stays the default/fallback.
Comparison/test pairs are indivisible i960 inline assembly; wrapping deltas and
floor shifts/products have explicit C semantics. No BSP traversal/order change.

Before deployment: independent million-case host arithmetic oracle, bounded
on-card scalar vectors against expected results and the original O0 body, exact
candidate text identity, native deterministic frames and build/admission gates.
Then fixed-low-detail A/B/B/A, 520 frames each, frames100–499 timing without
outlier exclusion; all frame/palette comparisons, native oracle, full paired
system audits, ownership, held-slot stall, held-frame STOP, heap drain and replay/
tamper checks retained. Record exact sources, binaries, captures and HTTP observer.
Save/hash-verify evidence before each reboot; restore public IPv6 HTTP afterward.
Do not attribute coarse BSP CPU sampling to exact helper CPU time.
