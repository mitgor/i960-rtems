# AcceleRAID 160 native RTEMS: second ten-step offline batch

Started 2026-11-16. This batch begins after the five-reply native ROM image and the Debian `myrs` guest reached hardware mailbox `0x8e` and the first memory-ring command. Execute dependencies without per-step confirmation. Work is limited to saved stock/candidate images, local source/builds and the exploratory QEMU/i960 model.
