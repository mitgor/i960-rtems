# Linux host side

The Linux PC owns PCI access, guarded admission, display/input delivery and
packet routing. Start with the [card profile](../card_profiles/README.md) and
the [stock-card reproduction guide](../docs/reproduce.md). Historical paths in
dated evidence describe the machine at the time of that test; they are not
automatically installed by cloning this repository.

The packet relay, NAT/routing rule installation, forwarding-value journal and
cleanup are source files in this checkout. There is no separate unpublished
iptables script required by the cooperative profile. A live Linux deployment
also needs its **matching, accepted** card image, kernel module, manifest,
Freedoom WAD where applicable, pinned Python wheel for the Doom gateway, and
current kernel headers. The [artifact index](../artifacts/README.md) identifies
the preserved inputs. The web wrapper expects to sit beside `autonet/`, its
matching module directory and `project/rtems/`; copying only the shell script
does not make a working deployment.

The convenience commands `./doom`, `./chip8` and `./rtems-console` connect to
the configured Linux host; they do not provision a new board. For Doom, the
installed `i960-doom-flat` shell wrapper is generated by the versioned stream
installer around a saved owner launcher. The original flat owner input is archived as
[`launcher.sh`](../artifacts/current/accele160-flat-20261018/launcher.sh), and
the installed gateway wrapper is archived as
[`installed-flat-launcher.sh`](../artifacts/current/doom-stream-20261018/installed-flat-launcher.sh).
Follow the [stream installation recipe](../game/doom/play/accele160/stream/README.md#reproduce-installation)
to recreate them with the correct bundle paths and hashes; do not start another
PCI owner to inspect a running one.

The [2026-10-23 installed-script snapshot](deployments/accele160-20261023/README.md)
records the exact wrappers and host-only gateway restoration helper found on
`mit@192.168.2.80`. The running AcceleRAID packet relay, broker and console
source files matched the tracked `rtems/accele160/runtime/` files byte-for-byte.
The Mac convenience commands now default to `.80`; set `I960_HOST` to override
that SSH endpoint. The current public IPv6 route needs revalidation because its
saved proxy interface differs from the host's present default IPv6 uplink.

The current PC may have a later combined AcceleRAID service than the historical
autonomous DAC960 web profile. Check its actual owner and bound module before
choosing a launcher. A terminal STOP or an uncertain DMA/owner result retains
the PCI resources until a verified reset; never force-unload them. Keep
visitor logs, local sockets, session captures and private machine credentials
out of Git. Record only aggregate results and the exact source/binary hashes.
